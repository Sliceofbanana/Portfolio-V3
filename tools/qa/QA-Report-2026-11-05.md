## Bug list

### BUG-01: `rate.genesisjr.com` is dead (Vercel DEPLOYMENT_NOT_FOUND)
- **Severity:** High · **Page:** https://rate.genesisjr.com · **Component:** DNS / Vercel domains
- **Steps:** Open https://rate.genesisjr.com
- **Expected:** a redirect to https://www.genesisjr.com/rates (as set in `vercel.json`)
- **Actual:** `404`, with the header `X-Vercel-Error: DEPLOYMENT_NOT_FOUND`. DNS points at Vercel, but the subdomain isn't attached to this project, so the redirect rule never runs.
- **Fix:** in Vercel → Project → Settings → Domains, add `rate.genesisjr.com` to this project. If the subdomain is no longer used, remove the DNS record and the redirect rule instead. If this link was ever shared with clients (cards, proposals, socials), they're hitting a dead page.
- **Status:** Open

### BUG-02: No custom 404 page
- **Severity:** Medium · **Page:** any unknown URL, e.g. `/this-page-does-not-exist`
- **Expected:** a branded 404 page with navigation back to the site
- **Actual:** Vercel's plain-text `The page could not be found / NOT_FOUND`, with no nav and no branding
- **Fix:** add a `404.html` at the repo root (Vercel serves it automatically). Use the normal header and footer, a short message, and links to Home / Work / Contact. Generate it from `src/pages/` like the other pages.
- **Status:** Open

### BUG-03: `robots.txt` missing
- **Severity:** Medium · **Page:** https://www.genesisjr.com/robots.txt
- **Actual:** 404. `sitemap.xml` exists (16 URLs, correct), but crawlers can't discover it from robots.txt.
- **Fix:** add `robots.txt` at the root:
  ```
  User-agent: *
  Allow: /
  Disallow: /api/
  Sitemap: https://www.genesisjr.com/sitemap.xml
  ```
- **Status:** Open

### BUG-04: Homepage contact block is clipped at 320 px
- **Severity:** Medium · **Page:** `/` → "(04) Contact" section · **Device:** 320 px wide (iPhone SE 1st gen, small Androids)
- **Steps:** set the viewport to 320 px and scroll to "Got something in mind?"
- **Expected:** both buttons and the social rows fit inside the column
- **Actual:** "REQUEST A QUOTATION" is cut off on the right, and the ↗ / → arrows of the LinkedIn / GitHub / Project form rows are hidden. `.st-socials` is 327 px wide in a 288 px column, and `main { overflow-x: clip }` hides the excess.
- **Cause:** `assets/street.css:590-591` puts the two `.st-btn` in a 2-column grid with `white-space: nowrap`. Their min-content width stretches the grid wider than the column.
- **Fix:** add `@media (max-width: 360px) { .st-contact .st-actions { grid-template-columns: 1fr; } }`, or allow the buttons to wrap. Fine at 375 px and wider.
- **Status:** Open

### BUG-05: No privacy notice on contact or quotation forms
- **Severity:** Medium · **Pages:** `/contact`, `/rates` · **Component:** intake form (`src/partials/intake-form.html`)
- **Actual:** the forms collect name, email, phone and business details with no statement of how the data is used or stored. The Philippines' Data Privacy Act (RA 10173) expects one.
- **Fix:** add one line above the submit button, e.g. *"I'll only use these details to reply about your project. They're never shared or sold."*, with a link to a short privacy section.
- **Status:** Open

### BUG-06: Design gallery lightbox has no previous / next
- **Severity:** Medium · **Page:** `/design` · **Component:** lightbox modal
- **Steps:** open any of the 60 images, then press → or look for arrows
- **Expected:** previous / next buttons and arrow-key navigation
- **Actual:** only a close (×) button. ArrowRight does nothing, so you have to close and reopen to see each image.
- **Fix:** add prev / next buttons with `aria-label`s, handle ArrowLeft / ArrowRight, and wrap around within the section.
- **Status:** Open

### BUG-07: Escape doesn't close the mobile menu
- **Severity:** Low · **Component:** header menu (`assets/site.js:16-27`) · **Device:** ≤900 px
- **Actual:** with the menu open, Escape leaves `body.menu-open` set. The toggle also has no `aria-controls`, and focus can tab out behind the overlay.
- **Fix:** on Escape, close the menu and return focus to `.menu-toggle`. Add `aria-controls` pointing to the nav's id.

### BUG-08: Work filter state is visual only
- **Severity:** Low · **Page:** `/work` · **Component:** filter buttons
- **Actual:** the active filter is shown only by the `.active` class. Screen readers can't tell which filter is selected.
- **Fix:** toggle `aria-pressed="true|false"` alongside `.active`.

### BUG-09: Heading levels skip h1 → h3
- **Severity:** Low · **Pages:** `/services`, `/work`, all five `/work/*` case studies
- **Fix:** change the first sub-heading to `<h2>`, or add an `h2` section heading (it can be visually hidden).

### BUG-10: Ionicons loaded from unpkg on every page for ~8 icons
- **Severity:** Low · **Component:** `<script src="https://unpkg.com/ionicons@7.1.0/...">` (×2 per page)
- **Actual:** a third-party runtime dependency fetches each SVG from unpkg. If unpkg is slow or down, icons pop in late or not at all, and the CSP has to allow `unpkg.com` for scripts and `connect-src`.
- **Fix:** inline the 8 SVGs (cart, chevron-down, globe, layers, logo-github, logo-linkedin, mail, pricetag), then remove unpkg from the CSP.

### BUG-11: Google Fonts requests 5 families
- **Severity:** Low · **Component:** `<link>` to fonts.googleapis.com
- **Actual:** Anton, IBM Plex Mono, Inter, Space Grotesk and Instrument Serif load on every page. Instrument Serif didn't render on the homepage.
- **Fix:** confirm where Instrument Serif and Inter are still used. Drop the families you don't need, or request them only on the pages that use them.

### BUG-12: Hero portrait not sized for mobile
- **Severity:** Low · **Page:** `/` · **Component:** hero `<img src="/Image/genesis.webp">`
- **Actual:** a 1080×1434 image (117 KB) is displayed at about 278 px wide on phones, and the frame shows empty for about 1–2 s on a cold load.
- **Fix:** add `srcset` with a ~600 px variant. Keep `fetchpriority="high"`.

### BUG-13: Client logos served as large PNGs
- **Severity:** Low · **Pages:** `/`, `/experience` · **Files:** `Image/clients/magis.png` (98 KB, 1200 px wide for a small logo), `wl-construction.png` (48 KB), `agila.png` (37 KB)
- **Fix:** convert them to WebP or SVG at about 2× their displayed size.

### BUG-14: Project links on Work need a check
- **Severity:** Low · **Page:** `/work`
- **Actual:** Buoy Watch links to `https://github.com/Sliceofbanana/buoy_watch.git`, which works but is the clone URL. Another card links to the old portfolio at `sliceofbanana.github.io/Genesis-Portfolio/`.
- **Fix:** drop `.git` from the Buoy Watch link. Confirm that linking the old portfolio is intended.

### BUG-15: Homepage price differs from the Rates page wording
- **Severity:** Low · **Pages:** `/` ("Websites around ₱40,000") vs `/rates` (Core "From ₱30,000", Growth "₱35,000–45,000")
- **Fix:** use the same "From ₱30,000" wording on the homepage, so the first number a client sees matches the rate card.

### BUG-16: No "* required" legend on forms
- **Severity:** Low · **Pages:** `/contact`, `/rates`
- **Fix:** add a small "* Required" note at the top of the form.

### BUG-17: `node_modules/` is committed to git
- **Severity:** Low (repo hygiene, not visible on the site)
- **Actual:** `node_modules/@vercel/analytics` (~80 files) is tracked, and `@vercel/analytics` doesn't appear to be loaded by any page.
- **Fix:** add `node_modules/` to `.gitignore` and run `git rm -r --cached node_modules`. Remove the dependency if it isn't used.
